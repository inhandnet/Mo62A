- EdgeAI 运行时升级至 TIDL 11_02_17_00 和 ONNX Runtime 1.23.0，同步更新 C7x 固件及配套执行器库。
- 更新板端 C/C++ SDK 头文件和推理接口，适配新版运行时，并提供匹配的预编译库。
- 使用新版 TIDL 重新编译九个随附模型，并更新基础根文件系统。
- QEMU SDK 构建按可用内存调整并行度，链接时使用随附的新版运行时库。
