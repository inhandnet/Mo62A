### Changed

- Updated the EdgeAI runtime to TIDL 11_02_17_00 and ONNX Runtime 1.23.0, with matching C7x firmware and execution-provider libraries.
- Updated the on-device C/C++ SDK headers and inference interfaces for the new runtime; included matching prebuilt libraries.
- Recompiled nine bundled models for the updated TIDL runtime and refreshed the base root filesystem.
- Adjusted the QEMU-based SDK build parallelism to available memory and ensured bundled runtime libraries are used during linking.

### Fixed

- Included external drivers in offline images using the same installation steps as direct SD card writing.

### Added

- Added a non-interactive offline image interface with input validation, overwrite protection and a read-only dry run.
- Added tag-triggered image builds, checksummed release assets and bilingual release metadata.
- Added the TIDL upgrade guide, troubleshooting notes and AM62A AI software-stack documentation.

### Validation scope

Automated release checks cover building, image structure, required files and checksums. They do not replace boot and peripheral testing on physical Mo62A hardware.
