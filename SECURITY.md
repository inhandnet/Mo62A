# Security reporting

Do not disclose suspected vulnerabilities, exploit details, credentials, signing keys or private keys in public GitHub issues, pull requests, or forum posts.

A dedicated private reporting channel for Mo products has not yet been published here. If you already have a private InHand support contact, ask them to confirm the appropriate security reporting channel before sharing sensitive details. Do not send vulnerability details through an unverified channel.

This repository publishes the board support package and OS image build for the Mo 62A. Ordinary bug reports and corrections (build scripts, device tree, documentation) can be submitted as issues or pull requests, provided they do not disclose a security vulnerability. Reports about the running OS image (kernel, firmware, preinstalled services) are security-relevant and belong in the private channel.
