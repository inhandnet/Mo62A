# imx219-preview (image build copy)

The maintained copy of this script lives in
[inhandnet/mo-examples](https://github.com/inhandnet/mo-examples/tree/master/products/mo62a/camera/imx219-preview)
(`products/mo62a/camera/imx219-preview/`). This directory is kept because the flash tool runs the
`Makefile` here and installs `/usr/local/bin/imx219-preview.sh` into the OS image.
Make changes in mo-examples first, then sync them here before a release.
