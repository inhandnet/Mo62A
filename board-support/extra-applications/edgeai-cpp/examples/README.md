# Edge AI C/C++ examples (image build copy)

The maintained copy of these examples lives in
[inhandnet/mo-examples](https://github.com/inhandnet/mo-examples/tree/master/products/mo62a/ai/edgeai-cpp)
(`products/mo62a/ai/edgeai-cpp/`). This directory is kept because `build.sh` installs it into the
OS image under `/usr/share/edgeai-cpp-examples/` when the SD card or offline image is
built. Make changes in mo-examples first, then sync them here before a release.
