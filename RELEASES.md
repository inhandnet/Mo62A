# Releases and changelog

[Latest release](https://github.com/inhandnet/Mo62A/releases/latest) ·
[All releases](https://github.com/inhandnet/Mo62A/releases) ·
[Full changelog — English](https://github.com/inhandnet/Mo62A/releases/latest/download/CHANGELOG.en.md) ·
[完整更新日志 — 中文](https://github.com/inhandnet/Mo62A/releases/latest/download/CHANGELOG.zh.md)

Each release includes an `.img.xz` OS image, SHA-256 checksums, `release.json`,
the complete English and Chinese changelogs up to that version, and a concise
release body (English by default, Chinese in an expandable section).

History starts at **V1.1.0**. Its curated source notes are in `release-notes/`.
Subsequent entries are generated from every commit between consecutive release
tags using the bilingual `Message` fields defined in [CONTRIBUTING.md](CONTRIBUTING.md).
There is no manually maintained cumulative changelog and no release-bot commit
back to `master`. Earlier handwritten notes remain available in Git history.

每个版本均提供截至该版本的完整中英文历史日志；首发基线为 V1.1.0，之后根据相邻 TAG
之间的提交自动生成。软件网站可使用一个版本化日志入口，无需为每个版本创建独立页面。
